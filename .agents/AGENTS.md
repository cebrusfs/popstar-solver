# PopStar Solver Agent Rules

## Commit Message Format
This is a standard GitHub-style open-source project.

*   **Format**: STRICTLY use `<component>: <title>`.
*   **No Conventional Commits**: Do NOT use conventional types like `chore`, `feat`, `fix`, `docs`, etc.
*   **Examples**:
    *   `ai: Implement BMCTS algorithm`
    *   `docs: Update AI Arena leaderboard with NRPA and BMCTS`
    *   `deps: Update Rust dependencies and migrate Python to uv`
    *   `engine: Rewrite Board as packed bitboard`
*   **Rule**: The `<component>` must be a simple, relevant module name (like `ai`, `engine`, `docs`, `deps`, `arena`).
